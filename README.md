# Simple file downloading console app + a test asp.net core file server

## To download a file using our console app:

```bash
StreamsTestApp.exe file download 
```

## Then we need to pass a file url and a place to save that file (at the current moment the default download directory supported only on Windows). The app starts to download that file immediately after:
